# Tercer Semestre - Universidad Técnica de Ambato
Repositorio oficial para la organización de prácticas experimentales (APEs) y tareas

## Estructura del Repositorio
- `APEs/`: Prácticas de aplicación y experimentación de los temas vistos en clase.
- `Tareas/`: Deberes y talleres prácticos en Java (Estructuras de Datos y Algoritmos).
  - `Tarea1/`: Ejercicios iniciales.
  - `Tarea2/`: Prácticas intermedias.
  - `Tarea3/`: Implementación de TDAs (Listas Circulares, Problema de Josephus, Simulador Round Robin, etc.).
